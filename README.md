# FRIDAY - Your AI Assistant 🤖

FRIDAY (Female Replacement Intelligent Digital Assistant Youth) - Inspired by Tony Stark's JARVIS!

## ✨ Features
- 🎤 Voice Recognition - Talk to FRIDAY
- 🗣️ Text-to-Speech Response
- 🌤️ Weather Updates
- ⏰ Reminders & Alarms
- 🔍 Smart Web Search
- 📱 100% Offline Android APK

## 🚀 Built With
- Python 3
- Kivy Framework
- Buildozer for Android Build

## 📦 How to Build APK
1. Push code to GitHub
2. Go to Actions tab
3. Wait for Build APK to turn green
4. Download APK from Artifacts

## 📥 Installation
1. Download APK from Actions → FRIDAY-APK
2. Allow Unknown Sources
3. Install & Enjoy!
